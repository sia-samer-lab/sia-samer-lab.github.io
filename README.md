# SAMER Lab website

Static website prepared for GitHub Pages. You can visit it on href[https://sia-samer-lab.github.io].

## Publish

Upload the contents of this directory to the root of the `sia-samer-lab.github.io` repository. The repository root must contain `index.html` together with the `assets` directory.

## Content that still needs confirmation

- Official institutional affiliation and postal address
- Official contact email
- Verified publication list and DOI links
- Member titles, profiles, and external links
- News, projects, recruitment information, and bilingual content

Do not restore the placeholder publications, funding figures, address, phone number, or contact form from the old draft without verification.
